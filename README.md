# Spatial Data Visualization

**A web application to visualize spatial data on COVID-19 and GDP trends in India.**  
Built with **ReactJS**, **Map APIs**, and **JavaScript libraries**, this tool enables users to explore geographical and statistical patterns through interactive maps and charts.

---

## ✨ Highlights  

- **Dynamic Maps**: Interactive, region-wise visualization of COVID-19 cases and GDP trends.  
- **Interactive Charts**: Data-driven charts for exploring trends over time.  
- **Easy Navigation**: Intuitive controls to toggle datasets and view region-specific details.  
- **Data Insights**: Helps users identify correlations and patterns effectively.

---

## 💡 About the Project

This project aims to bridge the gap between raw data and actionable insights by providing an intuitive web-based visualization tool. By focusing on **COVID-19 statistics** and **GDP trends in India**, the application offers users a unique perspective on how public health crises and economic factors interact across geographical regions.

The project emphasizes **data accessibility** and **user engagement** through:  
- **Interactive Maps**: Allowing users to explore region-specific data dynamically.  
- **Data-Driven Insights**: Highlighting patterns, correlations, and trends via visual aids like charts and graphs.  

The tool is designed to benefit:  
1. **Researchers**: To analyze the impact of COVID-19 on the economy at a regional level.  
2. **Policy Makers**: To identify high-risk areas and implement data-backed decisions.  
3. **Students and Analysts**: To understand spatial data representation and leverage modern tools like ReactJS and Map APIs for learning purposes.  

By combining robust frontend technologies with real-world datasets, this project demonstrates the power of visualization in understanding complex datasets, making it a valuable resource for educational, research, and practical applications.

## 🔧 Getting Started  

### Prerequisites  
- **Node.js** (v14+ recommended)  
- **npm** (or yarn, if preferred)  

### Installation  

1. **Clone the Repository**:  
   ```bash  
   git clone https://github.com/AviBejjam/vGIS.git
   ```  

2. **Navigate to the Frontend Directory**:  
   ```bash  
   cd vGIS/frontend  
   ```  

3. **Install Dependencies**:  
   ```bash  
   npm install  
   ```  

4. **Set Up Environment Variables**:  
   - Create a `.env` file in the `frontend` folder.  
   - Add your map API key

5. **Run the Application**:  
   ```bash  
   npm start  
   ```  
   - The app will open at `http://localhost:3000`.
